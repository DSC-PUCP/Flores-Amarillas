# AGENTS

This repository uses TanStack React Start + Vite + React 19 + TypeScript, with
Tailwind CSS, TanStack Router, TanStack Query, and Supabase. Use Bun as the
package manager.

No Cursor rules (.cursor/rules/ or .cursorrules) or Copilot instructions
(.github/copilot-instructions.md) are present at the time of writing.

## Commands

## Project Structure

- Routes are file-based under `src/routes` using TanStack Router.
- `src/routes/__root.tsx` defines the document shell, metadata, and providers.
- `src/routes/_layout.tsx` defines the authenticated layout with sidebar.
- `src/routeTree.gen.ts` is generated by TanStack Router; do not edit.
- Shared UI components live in `src/components/ui` (shadcn style).
- Feature code is grouped under `src/modules/*` (e.g. auth, items).
- Shared utilities are in `src/lib` and hooks in `src/hooks`.
- Assets and CSS modules live under `src/assets`.

## Code Style

Formatting (Biome)
- Indent: 2 spaces.
- Quotes: single by default.
- Trailing commas: ES5.
- Imports are organized automatically by Biome.
- Biome ignores `src/routeTree.gen.ts` and `src/styles.css`.

Imports
- Prefer path aliases: `@/` maps to `src/`.
- Order: external packages, then internal aliases, then relative imports.
- Use `import type` for types when possible.
- Do not add `React` default import; JSX runtime is automatic.

TypeScript
- Strict mode is on; fix type errors, do not use `any`.
- No unused locals or parameters.
- `noUncheckedSideEffectImports` is enabled; avoid side-effect imports.
- Use `zod` schemas in `src/env.ts` for env validation.

Components and hooks
- React components: PascalCase, exported as named or default.
- Hooks: `use*` naming, return stable shapes.
- Props interfaces/types: `ComponentNameProps` when explicit.
- Prefer `className` composition using `cn` from `src/lib/utils.ts`.
- Use `class-variance-authority` for variant-based UI styles.

Naming
- Files: kebab-case for UI components (e.g. `button-group.tsx`).
- Routes: follow file-based routing convention under `src/routes`.
- Modules: group by feature under `src/modules/<feature>`.

Error handling
- Prefer `throw error` for Supabase or fetch errors and let routes handle.
- Use TanStack Router `redirect({ to })` for guard flows.
- Server route handlers should throw `redirect` on navigation responses.
- For async mutations, use `useMutation` and surface errors in UI.

## Routing and Data

- Use `createFileRoute` in `src/routes/*`.
- Use `createRootRouteWithContext` in `src/routes/__root.tsx`.
- Use TanStack Query via `src/integrations/tanstack-query`.
- `AuthService` in `src/modules/auth/services.ts` is the auth entry point.
- Session data is loaded in `__root.tsx` and passed via route context.

## Styling

- Tailwind CSS is the primary styling system.
- CSS modules are used for component-specific effects.
- `src/styles.css` is a global stylesheet; edit carefully (not auto-formatted).
- shadcn UI conventions are used; check `components.json` for aliases.
- Prefer `data-*` attributes for component variants where used.

## Environment

- Env vars are defined in `src/env.ts` using `@t3-oss/env-core` + `zod`.
- Client env vars must be prefixed with `VITE_`.
- Use `env` from `src/env.ts` instead of `import.meta.env` directly.

## Localization

- i18n is configured in `src/i18n/index.ts`.
- Default language is `es`; supported: `es`, `en`.
- Cookies are used for language detection (`i18nextLng`).

## Generated / Do Not Edit

- `src/routeTree.gen.ts` (generated by TanStack Router).
- `dist/` (build output).
- `worker-configuration.d.ts` (generated by Wrangler).

## Notes for Agents

- Follow existing patterns in feature modules and shadcn UI components.
- Keep changes scoped; avoid refactors unless asked.
- Update or add tests when behavior changes.
- If adding new routes, ensure the path matches file-based conventions.
- When modifying styles, preserve the current visual language.

## Troubleshooting

- If env validation fails, check `.env` values for required `VITE_*` keys.
- If routing errors occur, re-run dev server to regenerate `routeTree.gen.ts`.
- For Cloudflare SSR issues, run `bun --bun run cf-typegen` and check `wrangler.json`.
