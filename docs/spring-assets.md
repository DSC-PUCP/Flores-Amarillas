## Landscape prompt

Create a website floral asset based closely on the reference: lush watercolor yellow spring blossoms with olive green foliage framing all four edges, especially rich corners, elegant botanical detail. Landscape 16:9. Remove ALL text, names and date. Remove isolated floating petals in center. Center must be completely empty flat warm cream #fff3d3 with a large oval negative space (middle 65% width and 70% height) for real HTML text. Keep flowers concentrated in outer edges. No lettering, no watermark. Retain reference's beautiful natural painterly texture. This will be animated as a floral border on a spring greeting website.

Adapt this exact watercolor yellow flower border into a PORTRAIT mobile website background, aspect ratio 9:19. Keep flowers naturally proportioned, never stretched. Dense yellow blossoms and olive foliage in corners, narrow delicate floral branches along left and right outer 12% edges, slightly fuller top and bottom 18%. Large clean empty warm cream #fff3d3 center for HTML title. No text, no floating petals. Same elegant botanical style as reference.
